## Start this project

To start this project you need to create your environment file first:

```bash
cp .env.example .env
```

You need to have docker installed.

To run the containers you can use the following command:

```bash
docker compose -f docker-compose.yml -f docker-compose.dev.yml up -d
```

This will start traefik and the php container.

Now you can access the application on http://localhost

The test route for accessing redis cursors is available at http://localhost/test
For this to work you need to add the following environment variables to your .env file with the correct values:

```dotenv
EXTERNAL_REDIS_URL
EXTERNAL_REDIS_HOST
EXTERNAL_REDIS_AUTH_TOKEN
```

## Stop this project

To stop the containers you can use the following command:

```bash
docker compose -f docker-compose.yml -f docker-compose.dev.yml down
```
